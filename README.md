# Ricui

Unified UI and iconography workspace for RIC projects.

## Workspace packages

- `@ric/ui-tokens` — shared design tokens
- `@ric/ui-core` — shared component contracts and accessibility baseline
- `@ric/icons` — shared icon catalog
- `@ric/emoji` — unicode emoji catalog used as semantic icons
- `@ric/ui` — single import entrypoint for all shared modules

## Getting started

```bash
npm install
npm test
```
